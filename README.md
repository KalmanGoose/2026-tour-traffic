## 📱 現場放人打卡操作流程（志工使用說明）

1. **抵達站點下車**：
   - 隨車隊/前導騎到分配路口停下。
2. **打開手機網頁**：
   - 選擇您的姓名（如：楊皓柄）。
   - 選擇分配的點號（P01 ~ P09 或 機動點）。
3. **抓取 GPS 座標**：
   - 點擊「**📍 點我抓取目前 GPS**」，手機自動偵測高精準度經緯度（精準度達 ±5m）。
4. **現場拍照（選填）**：
   - 點擊相機圖示，拍一張站立路口的全景照（系統會自動壓縮，山區上傳只需 1 秒）。
5. **送出打卡**：
   - 按下「**🚀 送出打卡**」，系統即時將經緯度寫入 Google Sheet 與 Google Drive。
   - 頁面亦提供「**📲 轉傳打卡座標至 LINE 群組**」按鈕，雙重保險！

## 🚀 部署上線教學（GitHub Pages + Google Apps Script）

### 步驟一：推送到 GitHub 並開啟 Pages
```bash
git add .
git commit -m "feat: 2026 tour de france traffic marshal web app"
git branch -M main
git remote add origin https://github.com/<你的用戶名>/<專案名稱>.git
git push -u origin main
```
- 前往 GitHub 該倉庫的 **Settings** ➔ **Pages** ➔ Branch 選擇 `main` ➔ 點擊 **Save**。
- 約 1 分鐘後即可產生手機可開啟的線上網址！

### 步驟二：設定 Google 試算表後端（接收打卡與照片）
1. 開啟 [Google 試算表](https://sheets.new)，建立新試算表。
2. 點擊頂部選單 **擴充功能** ➔ **Apps Script**。
3. 將本專案的 `Code.gs` 完整程式碼覆蓋貼上。
4. 點擊右上角 **部署** ➔ **新增部署**：
   - 類型選取：**網頁應用程式 (Web app)**
   - 執行身分：**我**
   - 誰可以存取：**所有人 (Anyone)** 👈 *務必選所有人*
5. 複製產生的網頁應用程式網址。
6. 打開已部署好的 GitHub Pages 網頁，點擊右上角 ⚙️ 齒輪，貼上該網址並儲存即可！
